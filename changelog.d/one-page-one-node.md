- **A page shown by two nodes at once is the one that shows** (zgx-desktop): one web view (or terminal) mounted at two live nodes, as a pane mounted again while its old node lingers, or the same page in a hidden pane, went to whichever the host placed last. If that was the hidden one, clicks where the page showed reached nothing, while the app's own controls still reacted. A page now shows, and takes input, at its node that is laid out visible (else the one registered last), and nowhere else.
