- **A text cut to fit takes the width it was given** (zgx-gpu): a truncated or line-clamped text measured as wide as the glyphs before its ellipsis (343 where the web's label box was 346.2), so what followed it started early. As under CSS `text-overflow`, its box now fills the width it was offered whenever it is cut, and a text that fits keeps its own.
