- **A menu shortcut acts before the key typed right after it** (zgx-desktop): a key typed a moment after a shortcut that moves focus (⌘N opening a new document, say) reaches what the shortcut focused, not what had focus before it. A shortcut the window's keymap takes is carried out as soon as its key is handled, on every platform, and a macOS menu item chosen by its key is carried out before the next window event.
