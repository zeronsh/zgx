- `zgx::native_control`: the system's switch and tab bar where a host has them (iOS's `UISwitch` and `UITabBar`), drawn elsewhere; and what a host provides for the system's own behaviour (haptics, alerts and action sheets, sharing, system menus, the escape gesture, an edge effect, a keyboard bar, pull to refresh, native pans). Hosts without them see nothing change.
