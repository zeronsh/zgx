- **`ui.markdown_view` draws its prose in an app's own look** (zgx-script): `style` gives its paragraphs `ui.rich`'s options and each kind of run (`strong`, `em`, `strike`, `code`, `link`) `ui.span`'s, tokens and functions resolved as theirs are, and `gap` the room between its blocks; `on_link(target, e)` takes a link's click (`true` keeps a web address shut) and `link_menu(target, e)` makes its menu. A chat drawing its replies in Rust keeps the look it drew in script, while a streaming paragraph is re-spanned in place with no script. `autolink` (on `ui.markdown` too) makes web addresses written bare links, as GitHub's autolinks. A span's `text_size` takes a token (`"$font.size.sm"`). `veil = { key, seed }` fades a streaming reply's new words in as they arrive, at the pace they come. A streamed text edited near its end (math read into code as a `$` closes) parses again from the block it changed, keeping those before it. `chip(target, text)` and `attached` draw links elsewhere than the web and words naming what a message carries as the app's chips, asked again as what they read changes. `find = { query, current, reveal }` marks a find's matches (`style.mark`, `style.mark_current`) and brings the block holding the current one into view.
