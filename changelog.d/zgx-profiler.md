- **`zgx-profiler`** (`zgx-profiler`): an attachable frame profiler for desktop apps. `zgx_profiler::attach(cx, Config::default())` records every frame and draws an inert HUD above the interface (F12), with frame pacing (p50/p95/p99 and late frames), the frame's phase split, damaged rects and their area (F11 outlines them), signals written and effects run with the widest cascade and thrashing flags, and resident memory; the overlay's own repaints are kept out of the app's numbers, and it rewrites itself at 30 Hz so an idle window stays idle. `Profiler::export` writes a Chrome trace (phases, per-frame damage rects, reactive work, counters and markers) for `ui.perfetto.dev`. `PROFILING.md` says how to read it.
- **A window publishes the frames it finishes** (zgx-desktop, `zgx::diagnostics`): `WindowContext::diagnostics` hands each finished frame — its damage rects, the nodes laid out, painted and composited, and whether it drew the whole window — to whatever watches, before the next frame is laid out, so a watcher's own changes paint in it. Nothing is built with nothing watching.
