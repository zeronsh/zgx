- **An app can tell when a node's context menu shows** (zgx, zgx-script, zgx-dom): a state can follow a right-click menu, true while it shows and false as it closes, by Escape, a pick, a click outside, Tab, the window losing focus, a newer menu or the node going; writing it false closes the menu. A PDF reader hides its floating selection popover while the page's menu is open, as the web's does. Nodes that don't ask pay nothing.
