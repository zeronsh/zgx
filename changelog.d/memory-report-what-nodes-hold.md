- **A memory report names what an interface holds beyond its slots** (zgx, zgx-script, zgx-gpu, zgx-desktop): nodes' child lists, layout results, advanced layouts, extras and plain texts, and the scene's tables; the reactive runtime's effects (each closure's captures and what it reads), the signals they read and the values effects own; input listeners; semantics; what the interface keeps per node; the font database and how many fonts are loaded; the accessibility projection; and, of a script's VM, the pages pooled outside the program's heap. Each is worked out only when a report asks. A page of a thousand nodes at rest has 87% of its heap named, which a test holds above 85%.
