- **Base UI focus hooks, tooltip groups, a baseline icon, and fixes** (zgx, zgx-script, zgx-desktop): `View::initial_focus` / `final_focus` (`FocusTarget::Id`, `None`; Luau `initial_focus` / `final_focus` = an id or `false` on `ui.modal`, `ui.popover`, `ui.menu`) pick where focus lands as it opens and closes. `View::tooltip_group(TooltipGroup)` (Luau `tooltip_group = { delay, close_delay, reshow_within, reshow_delay }`) is a group whose tooltips wait and reshow together and apart from any other; `Tooltip::close_delay` / `hover_delay` (Luau `tooltip_close_delay`). A span's icon takes `align = "baseline"` (`IconAlign::Baseline`): its bottom edge on the text's baseline, the line growing to hold it, as an inline image in CSS. A hover-opened lazy popover opens on its first hover (its tracker is wired before its panel is built).
- **A scroll view given only a cap is as large as its content up to it** (zgx): `max_h` / `max_w` without a size of its own measured the default 320 by 240 clamped by the cap; it now takes its content's size up to the cap, as CSS's overflow box does, and scrolls what passes it.
- **A held popup's items are no controls** (zgx, zgx-script, zgx-desktop): while the app is at the back a popup wanted open is held, not shown nor hit, so `ui.controls` no longer lists its items and `ui.press` on one returns false instead of pressing the window under it (which dismissed the popup without running the item). A session that renders as covered (`ZGX_RENDER_WHEN_COVERED`, `ZGX_OFFSCREEN`) takes no focus and counts as forward, so its popups open and take presses.
