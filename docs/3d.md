# 3D scenes in Rust

`zgx-3d` is a retained 3D world shown in any box: meshes in metallic-roughness materials, lights, a camera, and glTF models with their textures, animations and skins. A world draws a frame only when it changes, so a still scene costs nothing, and its pipelines and buffers are made with its first frame. In Luau the same world is [`ui.scene3d`](reference/3d.md).

```toml
[dependencies]
zgx-3d = { version = "0.1", features = ["gltf"] } # gltf: Model, and PNG and JPEG textures
```

## A world

A `World` holds objects (`Object::mesh`, or `Object::group` to place several as one), lights and a camera. Its `view()` is a [GPU view](gpu-views.md), so the box showing it clips, rounds, fades and hit tests like any other.

```rust,no_run
use zgx::compose::prelude::*;
use zgx_3d::*;

let world = World::new();
world.set_background(Some(0x10141b));
let group = world.add(Object::group());
let cube = world.add(Object::mesh(Geometry::cuboid(1., 1., 1.), Material::rgb(0x4a90e2).with(0., 0.35)).child_of(group));
world.add(Object::mesh(Geometry::sphere(0.35, 32), Material::rgb(0xd9a441).with(1., 0.3)).at([1.3, 0., 0.]).child_of(group));
world.add_light(Light::Directional { direction: vec3(-0.5, -1., -0.4), color: [1., 1., 1.], intensity: 2.5 });
world.set_camera(Camera::looking_at([0., 1.5, 4.], [0., 0., 0.]));

let view = gpu_view("A cube and a sphere", world.view()).w_full().h(320.);

// One change, one frame:
world.update(cube, |object| object.transform.rotation = Quat::from_euler(0., 0.5, 0.));
```

`Geometry` has `cuboid`, `sphere`, `plane`, `cylinder`, `cone` and `torus`, and `Geometry::new(vertices, indices)` takes your own triangles. Each geometry's meshes draw in one instanced call.

## Camera controls

`OrbitControls` answers a view's input as a model viewer does: drag to turn, right-, middle- or Shift-drag to pan, scroll or pinch to zoom (Shift-scroll pans), and, focused, the arrow keys turn (pan with Shift), `+` and `-` zoom and Home comes back. `zoom`, `pan` and `inertia` are fields to turn off. Hand it each event; its `Answer` says what happened.

```rust,no_run
use std::{cell::RefCell, rc::Rc, time::Instant};
use zgx::{compose::prelude::*, input::InputEvent};
use zgx_3d::*;

let world = World::new();
let controls = Rc::new(RefCell::new(OrbitControls::new(Orbit { distance: 4., ..Orbit::default() })));
world.set_camera(controls.borrow().orbit.camera(world.camera()));

let view = gpu_view("A model", world.view()).w_full().h_full().focusable(true).on_event({
    let world = world.clone();
    move |event| {
        let modifiers = match &event.event {
            InputEvent::KeyDown { modifiers, .. } => *modifiers,
            _ => event.pointer_modifiers(),
        };
        let mut controls = controls.borrow_mut();
        let answer = controls.handle(&event.event, modifiers, Instant::now());
        if answer.moved {
            world.set_camera(controls.orbit.camera(world.camera()));
        }
        if answer.taken {
            event.prevent_default();
        }
    }
});
```

`answer.coasting` says a flick is coasting on: call `coast(seconds)` a frame at a time until it returns `false`, setting the camera each time ([the `model` example](../crates/zgx-3d/examples/model.rs) does). Set `inertia = false` for reduced motion. `Orbit` alone is the arithmetic: `drag`, `zoom`, `pan` and `camera(base)`.

## Models

With the `gltf` feature, `Model::from_bytes` reads a `.glb` or a `.gltf` whose buffers are inline, and `Model::from_bytes_with` reads one whose buffers sit beside it. `World::add_model` adds it as one group to place, turn and scale. A model brings its default scene's nodes, its meshes (with smooth normals where it has none), its materials and their base colour, metal-roughness, normal, emission and occlusion textures, where those sit (a second set of texture coordinates, samplers' wrapping, `KHR_texture_transform`), its vertices' colours, its skins and its morph targets, and its lights (`KHR_lights_punctual`), each following its node, and its glass (`KHR_materials_transmission`, `KHR_materials_ior`, `KHR_materials_volume`, with their transmission and thickness textures) and clear coats (`KHR_materials_clearcoat`, with its coat, roughness and normal textures; `World::set_clearcoat` gives a mesh one) and how its dielectrics reflect (`KHR_materials_specular`'s factor and colour and `KHR_materials_ior`'s index; `World::set_specular`). `Placed::cameras(&world)` gives its cameras where its nodes are, for `World::set_camera`.

To play its animations, place it with `World::place_model`, which keeps its nodes' objects, and give it an animator. `Model::clips` lists its clips (`clip(name)` finds one). An animator plays them by the world's frames, at each frame's time (never the wall clock, so a video renders the same poses each time): while a clip plays the world draws by itself, and paused (`set_animator_speed(id, 0.)`), stopped or done it draws nothing.

```rust,no_run
use zgx_3d::*;

fn play(world: &World, bytes: &[u8]) -> Result<(), ModelError> {
    let model = Model::from_bytes(bytes)?;
    let placed = world.place_model(&model);
    let animator = world.add_animator(&placed);
    let (Some(walk), Some(wave)) = (model.clip("Walk"), model.clip("Wave")) else { return Ok(()) };
    world.play(animator, walk, Play::new());
    // Later: wave with the upper body over the walk, fading in over a fifth of a second.
    let spine = placed.node(3).expect("the spine's node");
    world.set_layer(animator, 1, Layer::new().mask(Mask::new().below(spine, 1.)));
    world.play(animator, wave, Play::new().layer(1).fade(0.2).once());
    Ok(())
}
```

- **Layers** are counted from 0, the lowest. Each has a weight, a `Mask` (nodes, or a node and all under it with `Mask::below`, each taking 0 to 1 of the layer) and a blend: `Layer::new()` takes the place of the layers under it by its weight, `Layer::additive()` adds how far its clip has moved from its first key (a lean, a breath).
- **Within a layer** a clip played with `fade(seconds)` crossfades from what played there; `World::stop(id, layer, fade)` fades a layer out.
- **`Play`** says the layer, the fade, the `speed` (negative plays backwards), `once()` (held at its end; looping otherwise) and `from(seconds)`.
- **Events**: `clip.with_event(0.4, "step")` is reported each time the clip passes 0.4 s, in `World::animator_update(id).events`.
- A frame finds each clip's key times once for all its channels, from where the last frame left them, and writes only the nodes whose places changed. A gap between frames longer than a quarter second (the view hidden) is taken as a quarter second: an animation goes on where it was.

`Placed::pose` poses one clip at any time by hand, drawing a frame only if something moved.

`cargo run --release -p zgx-3d --features gltf --example model -- FILE` shows a file and plays its first clip.

## Textures

`Texture::from_rgba8` takes pixels and `Texture::decode` a PNG or JPEG. `World::set_texture(id, Some(texture))` gives a mesh its base colour, and `World::set_map(id, map, Some(texture))` the rest: `Map::MetalRoughness`, `Map::Normal`, `Map::Emission` and `Map::Occlusion`, and for a mesh light passes through, `Map::Transmission` (how much passes, red) and `Map::Thickness` (how deep, green), and for a coated one `Map::Clearcoat` (how much coat, red), `Map::ClearcoatRoughness` (how rough, green) and `Map::ClearcoatNormal` (which way the coat faces), each read at its first texture coordinates as they are. A normal map's frame comes from the screen's derivatives, so meshes need no tangents. A texture decoded from a file holds the file, and its decoded pixels only until a renderer has uploaded them. A scene without textures binds none.

## Skins

`Geometry::with_skin(joints, weights)` gives each vertex up to four joints, and `World::set_skin(id, Some(skin))` binds a mesh's object to a `Skin::new(joints, inverse_binds)`: objects as joints, up to `MAX_JOINTS` (256). The GPU places each vertex by its joints' matrices, so moving the joint objects bends the mesh, and its shadow and picking follow the pose. glTF models bring theirs.

```rust,no_run
use zgx_3d::*;

fn bend(world: &World) -> Result<(), &'static str> {
    let root = world.add(Object::group());
    let tip = world.add(Object::group().at([0., 1., 0.]).child_of(root));
    let bar = Geometry::cuboid(0.2, 2., 0.2);
    // Each vertex follows the joint at its end of the bar.
    let (joints, weights): (Vec<_>, Vec<_>) = bar
        .vertices()
        .iter()
        .map(|v| ([if v.position[1] > 0. { 1u16 } else { 0 }, 0, 0, 0], [1., 0., 0., 0.]))
        .unzip();
    let mesh = world.add(Object::mesh(bar.with_skin(joints, weights)?, Material::rgb(0xd9a441)));
    let inverse_binds = vec![Mat4::IDENTITY, Mat4::from_transform(vec3(0., -1., 0.), Quat::IDENTITY, Vec3::ONE)];
    world.set_skin(mesh, Some(Skin::new(vec![root, tip], inverse_binds)?));
    // Turning the tip's joint bends the bar:
    world.update(tip, |object| object.transform.rotation = Quat::from_euler(0.6, 0., 0.));
    Ok(())
}
```

## Light

`World::set_environment(Some(Environment::studio()))` lights every surface from all around, its reflections sharp in polished metal and blurred in rough. The studio is built in; `Environment::decode_hdr` reads a Radiance `.hdr` image (equirectangular), and `from_equirect` and `from_cube` take linear RGB. `intensity` brightens one and `rotated` turns it. Making one takes 11–16 ms, so do it off the main thread; the studio is made once for the app.

With the `lighting` feature, a world shades every point and spot light, not only the eight nearest the camera's target: past eight (or with `World::set_clustered_lights(true)`) its view is cut into 16 by 9 tiles and 24 slices of depth, each light is listed in the clusters its reach touches, and each pixel shades with its own cluster's lights alone, so hundreds of lights cost about what the few reaching each pixel do. The lists are made on the CPU, and made again only when a light, the camera or the view's size changes: 256 lights seen by a moving camera cost about 0.4 M instructions a frame, binned and uploaded. A device without storage buffers in its shaders (some GL) shades the eight nearest instead.

```rust,no_run
use zgx_3d::*;

let world = World::new();
for i in 0..256 {
    let (x, z) = ((i % 16) as f32 * 2. - 15., (i / 16) as f32 * 2. - 15.);
    world.add_light(Light::Point { position: vec3(x, 0.5, z), color: [1., 0.8, 0.6], intensity: 2., range: 1.5 });
}
```

Lights can be given in physical units: `Light::point(position)` and `Light::spot(position, direction)` make a `PointLight` whose brightness is in candela (`candela`) or lumens (`lumens`: a point's or a spot's is `lumens / 4π` candela, so narrowing a spot keeps how bright it is where it shines), with a colour, a `range` it falls smoothly to nothing at, a `cone` for a spot, and a `radius`: a light as big as a bulb falls off from its surface, so it lights what it nearly touches without a burning point, and its highlights on shiny surfaces are as wide as it looks. `World::add_point_light` adds one. `Light::Point`'s `intensity` is in candela too, so a world written before means the same. A light with a radius shades through clusters.

```rust,ignore
// With the `lighting` feature.
use zgx_3d::*;

let world = World::new();
world.add_point_light(Light::point([0., 2.4, 0.]).lumens(800.).color([1., 0.9, 0.8]).range(8.).radius(0.04));
world.add_point_light(Light::spot([2., 3., 1.], [-0.5, -1., -0.2]).lumens(4000.).cone(0.3, 0.5));
```

`World::set_shadows(true)` has the sun, the first directional light, cast soft shadows from opaque meshes. It costs a 2048 by 2048 depth map (16 MB) and a depth pass drawn again only when meshes or the sun move, not the camera.

`World::set_tone_mapping` says how lit colours reach the display's range: `ToneMapping::Neutral` (the default) keeps colours as the material says and rolls highlights off, `Aces` is the filmic curve, and `Linear` clamps. `World::set_exposure(stops)` doubles the light for each stop.

`World::set_samples(1)` draws hard edges at a quarter of the colour and depth memory; the default, 4, multisamples and smooths highlights on fine curves too, for about 1% more GPU work.

```rust,no_run
use zgx_3d::*;

let world = World::new();
world.set_environment(Some(Environment::studio().intensity(0.8).rotated(0.5)));
world.set_shadows(true);
world.set_tone_mapping(ToneMapping::Aces);
world.set_exposure(0.5);
```

## What the device can do

`World::caps()` says what the device the view draws with can do, once a frame has been drawn (`None` before: the device is the window's). `Tier::A` (Metal, Direct3D 12, Vulkan) runs compute, binds storage buffers and textures in every stage and draws indirectly; `Tier::B` (GL) is taken to do none of those. `Caps` also says whether timestamps can be taken, which compressed formats it samples, whether shaders can trace rays (`ray_queries`) or index arrays of textures, and its compute limits. It's read again when the view moves to another device.

```rust,no_run
use zgx_3d::*;

fn plan(world: &World) {
    match world.caps() {
        Some(caps) if caps.compute => { /* GPU particles, compute passes */ }
        Some(_) => { /* tier B: CPU fallbacks */ }
        None => { /* not drawn yet: ask again after the first frame */ }
    }
}
```

## GPU data and compute

With the `compute` feature, a world holds buffers and textures of the app's on the device and runs WGSL compute passes over them, for simulations, generated textures, or anything a material or emitter then reads.

`World::add_buffer` makes a `GpuBuffer` (`BufferDesc::storage::<T>(count)`, `bytes(n)` or `from_slice(&values)`), and `World::add_texture` a `GpuTexture` (`TextureDesc::storage(width, height, Format::Rgba16Float)`), zeroed. The handle owns it: the world counts its bytes in `World::memory()` while it (or a pass binding it) lives, refuses more than its cap (`set_memory_cap`, 256 MiB to begin with), and lets the device's copy go when the last clone drops. `buffer.write(offset, &values)` lands before the next frame's passes.

`World::add_compute` adds a `Compute`: the shader, the resources it binds by the names it gives them and how (`Access::Read`, `Write` when the pass writes all of it, or `ReadWrite`), how many workgroups (`dispatch`) or invocations (`threads`), and when: `every_frame()`, `at_rate(per_second)` of frame time, or `on_demand()` (once when added, again on each `World::run_compute`). A uniform the shader names `frame` holds the frame's `time`, `delta` and `index`, and a `sampler` is a linear one.

```rust,ignore
let waves = world.add_buffer(BufferDesc::storage::<[f32; 4]>(256 * 256))?;
let height = world.add_texture(TextureDesc::storage(256, 256, Format::Rgba16Float))?;
let pass = world.add_compute(
    Compute::new(include_str!("waves.wgsl"))
        .buffer("waves", &waves, Access::ReadWrite)
        .texture("height", &height, Access::Write)
        .threads([256, 256, 1])
        .every_frame(),
)?;
let read = waves.read(0..64); // resolves 1 to 3 frames later
```

The shader is parsed and checked when the pass is added: a mistake comes back as `ComputeError::Shader` at the shader's own lines, and bindings that don't match the shader's declarations, workgroups past the limits every tier A device has, and an order that can't hold are refused there too. It's compiled on a thread of its own, so no frame waits for it; `World::compute_status` says when it's ready. Where the device runs no compute (`caps().compute` is false: GL), `add_compute` returns `ComputeError::Unsupported`.

Passes run before the frame is drawn, or after it (`.at(Point::AfterFrame)`), in the order added, except that a pass writing a resource whole runs before passes added earlier that read it. A world with an enabled every-frame or rated pass keeps drawing; an on-demand one draws the frame it runs in, and a world whose passes aren't due draws nothing.

`buffer.read(range)` and `texture.read()` copy what the GPU holds after a frame into a `Readback`, which resolves a few frames later (`try_take` each frame, or `.await` it). Reads go in the order asked, at most `set_readback_budget` bytes a frame (64 KiB to begin with); a larger one takes more frames, and none makes a frame wait for the GPU.

## Particles

With the `particles` feature, `World::add_emitter` adds an `Emitter`: a pool of particles born where its `Spawn` says (`point`, `box_`, `sphere`, or `cone` along an axis) at a `rate` a second or in a `burst`, living a random time in their `lifetime`, moving from their `velocity` under their `force`s (`Gravity`, `Constant`, `Drag`, `Wind`, `Swirl`), colliding with a plane (`Collide::Plane`, bouncing, sticking or dying), and drawn as soft billboards or streaks along their motion, over what's behind them or adding light to it, their colour and size changing over their life.

```rust,ignore
let rain = world.add_emitter(
    Emitter::new(200_000)
        .spawn(Spawn::box_([-40., 30., -40.], [40., 32., 40.]).rate(60_000.))
        .lifetime(0.6..0.9)
        .velocity([0., -22., 0.], 1.5)
        .force(Force::Gravity)
        .force(Force::Wind([2., 0., 1.]))
        .force(Force::Drag(0.1))
        .collide(Collide::Plane { height: 0., then: Response::Die })
        .draw(Shape::Streak { length: 0.04 }, Blend::Alpha)
        .size(0.01..0.015)
        .color([0.7, 0.75, 0.8, 0.5]),
);
world.set_emitting(rain, false); // what has fallen finishes falling
```

A pool holds `Emitter::new`'s count at once; a full one replaces its oldest. Particles are updated by a compute pass, or on the CPU where the device runs none (`caps().compute` false), at most `CPU_PARTICLES` (16,384) an emitter. A world draws while an emitter emits or any of its particles may live, then settles: a burst that's over lets it go idle. `World::burst` spawns more at once and `move_emitter` moves where it spawns.

`particles_bench` measures their GPU time at 1080p against a world without them. Particles are drawn in front of the meshes for now; drawing them against the scene's depth (and soft where they meet it) comes with the renderer's pass list.

## Picking

`World::pick(point, size)` says what a point of the view's box shows: a `Hit` with the `object`, the `point` on it in the world and its `distance` from the camera. It's found on the CPU from the meshes' triangles, so a world never picked costs nothing.

```rust,no_run
use zgx_3d::*;

fn clicked(world: &World, x: f32, y: f32, width: f32, height: f32) -> Option<ObjectId> {
    world.pick((x, y), (width, height)).map(|hit| hit.object)
}
```
