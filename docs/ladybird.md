# Ladybird pages

A web view can show its page in [Ladybird](https://ladybird.org) instead of the platform's engine: `WebViewOptions { engine: WebEngine::Ladybird, .. }` in Rust, `engine = "ladybird"` in Luau (`ui.webview`, `ui.web`). The default stays the platform's (WKWebView, WebView2, WebKitGTK). The rest of the web view's API is the same; what Ladybird pages can't do yet is [below](#what-they-do-and-dont-yet).

```sh
# Build the host with Ladybird, from its pinned release (about 50 minutes on 16 cores the first time, then
# cached); it prints the install it made:
python3 crates/zgx-ladybird-sys/ladybird/build.py --print-install-dir
# Then run against that install:
ZGX_LADYBIRD_DIR=/path/to/install cargo run -p zgx-desktop --features ladybird --example web_view -- --ladybird
```

## How a page is shown

Ladybird runs in a process of zgx's, `zgx-ladybird-host` ([crates/zgx-ladybird-sys](../crates/zgx-ladybird-sys/README.md)), one for the app. It links Ladybird's LibWebView, which starts Ladybird's helpers (WebContent per site, the Compositor, RequestServer, ImageDecoder, ...). A crash in any of them ends the app's Ladybird pages (`WebViewEvent::ProcessTerminated`), never the app.

Ladybird's Compositor paints each page into backing stores in shared memory. The host sends the app each store once (its file descriptor) and then, for each frame, which store shows it and what changed. The page's box is a GPU view (`zgx::gpu_view`) whose painter uploads only that part into its texture and tells the host it's done, after which the Compositor may paint into the store again. So the page is clipped, rounded, faded, transformed and blurred under glass as any image is, and zgx content over it is ordinary paint, the same on X11, Wayland and macOS. A page that draws nothing sends nothing: an idle page costs no frames and no CPU.

Input goes to the page's box as to any node's and on to Ladybird: pointer presses (with double and triple clicks), moves, leaving, wheel and trackpad scrolling, keys with their modifiers, typed text, input methods' compositions and commits, and focus. The page's cursor is its box's.

The host is found in the install `ZGX_LADYBIRD_DIR` names, else in `zgx-ladybird` beside the app's executable (where an app that ships Ladybird pages puts the install). Without one (or a host that won't start), a Ladybird page shows its placeholder and says why once on stderr. Without the feature nothing of this is compiled, and the option shows the placeholder too.

## What they do and don't yet

| | Ladybird pages |
| --- | --- |
| Load a URL or HTML, reload, stop, back and forward, history steps | yes |
| Title, URL, loading, history state and events, visits | yes |
| The hovered link and the page's theme colour | yes |
| The page's icon (`favicons`) | yes |
| Clipboard: what pages copy goes to the system's, pastes read it | yes |
| Editing commands, reload ignoring the cache, why WebContent ended | yes; a page that stops answering isn't said |
| Snapshots, of what shows and of the whole page | yes: what shows from the frame zgx holds, the whole page painted by WebContent |
| Pointer, wheel, keys, input methods, focus, cursor | yes |
| Resize and the display's scale | yes |
| Zoom (`set_zoom`) | yes |
| `evaluate_js` | runs the script; its result comes back as an error saying Ladybird pages don't return one yet |
| Page messages, injected scripts, app schemes, downloads, find, print, devtools, clearing a site's data | not yet: they answer as a platform that can't |
| Platforms | Linux, built and tested; macOS, the host copies each frame's changes out of the Compositor's IOSurfaces (importing them directly is to come), not yet built here; Windows not yet |

## Notices

Ladybird is under the BSD 2-Clause license. An app that ships Ladybird pages ships, with its own notices:

- **`LICENSES.txt`** from the host's install: Ladybird's licence and those of everything its build includes (vcpkg's libraries, Ladybird's Rust crates), generated by Ladybird's build. zgx-ladybird-sys's build fails if it's missing.
- **FFmpeg** (avcodec, avformat, avutil, swresample: `lib/lib*-ladybird.so.*`), which Ladybird uses to decode audio and video, is under the **GNU LGPL 2.1 or later**. The build makes it without FFmpeg's GPL, version 3 and non-free parts, and fails otherwise. It ships as shared libraries, which a user can replace with their own builds of the same FFmpeg version (relinking). The app ships the LGPL 2.1's text (FFmpeg's `COPYING.LGPLv2.1`, in `LICENSES.txt`) and offers FFmpeg's source: FFmpeg 9.0.2 from <https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz> with the vcpkg port Ladybird 2026.47.8 builds it with (`Meta/CMake/vcpkg/overlay-ports/ffmpeg` in Ladybird's repository at that release), or a copy of them the app keeps for three years.
- **adblock-rust** (the `adblock` crate 0.13.5, Ladybird's content blocker) is under the **Mozilla Public License 2.0**, and so is the **Public Suffix List** data in libpsl and in the `psl` crate. Shipped unmodified, the MPL asks that recipients be told where the source is: <https://crates.io/crates/adblock/0.13.5> (<https://github.com/brave/adblock-rust>), <https://github.com/publicsuffix/list>. Both are in `LICENSES.txt`.
- **Noto Emoji** (`share/Lagom/fonts/NotoEmoji.ttf`) is under the **SIL Open Font License 1.1**, whose text ships with it: <https://github.com/googlefonts/noto-emoji/blob/main/fonts/LICENSE>.

Nothing else in the build is copyleft: the [licence audit](#licence-audit) has each part. Ladybird's content-blocker filter lists (EasyList and others, under the GPL 3 or CC BY-SA 3.0) are not in the build; Ladybird fetches them at run time only if their subscriptions are turned on, which zgx's host leaves off.
